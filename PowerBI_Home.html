Glossário Consolidado

Serviço Power BI
Plataforma em nuvem (app.powerbi.com) para publicar, compartilhar e colaborar em relatórios e dashboards.
Power BI Desktop
Aplicativo Windows gratuito para conectar, transformar e modelar dados e criar relatórios.
Microsoft Fabric
Plataforma de análise "tudo em um" da Microsoft, da qual o Power BI é uma das cargas de trabalho principais.
Modelo semântico
Antes chamado de "dataset" — contêiner de dados usado para construir relatórios, dashboards e apps; pode combinar múltiplas fontes.
Relatório
Uma ou mais páginas de visuais interativos baseados em um único modelo semântico.
Dashboard
Uma única página (canvas) com blocos (tiles) de visuais fixados a partir de relatórios; não suporta filtragem, mas suporta Q&A e alertas.
App
Coleção de dashboards, relatórios e modelos semânticos empacotados para compartilhamento com indivíduos, grupos ou organizações.
Workspace
Área colaborativa onde designers armazenam e gerenciam dashboards, relatórios e outros itens do Fabric.
Tile (bloco)
Uma única visualização exibida em um dashboard, fixada (pinned) a partir de um relatório.
Pin (fixar)
Ação de adicionar uma visualização de um relatório a um dashboard.
Q&A
Recurso de IA que permite fazer perguntas sobre os dados em linguagem natural e obter visuais como resposta.
Copilot
Assistente de IA integrado ao Power BI que ajuda a criar relatórios, analisar dados e gerar resumos em linguagem natural.
Capacidade (Capacity)
Conjunto dedicado de recursos usado para desempenho e escalabilidade (SKUs Fabric F ou Power BI Premium P).
Fabric (Grátis)
Licença por usuário gratuita — permite criar conteúdo no Meu workspace e consumir conteúdo em capacidade Premium (F64+).
Power BI Pro
Licença paga por usuário que permite publicar, compartilhar e colaborar com outros usuários Pro.
Premium Per User (PPU)
Licença que dá acesso à maioria dos recursos Premium por usuário, sem exigir capacidade dedicada da organização.
Dataflow
Coleção de etapas de transformação de dados armazenada no serviço, permitindo preparação de dados reutilizável e centralizada.
Lakehouse
Item do Microsoft Fabric que armazena dados de forma unificada, combinando características de data lake e data warehouse.
Direct Lake
Modo de consulta do Fabric que lê dados diretamente do OneLake, sem necessidade de importação ou cache.
DirectQuery
Modo de conexão em que o Power BI consulta a fonte de dados original em tempo real, sem importar os dados para o modelo.
Esquema em estrela (star schema)
Modelo de dados com uma tabela de fato central cercada por tabelas de dimensão relacionadas a ela.
Tenant
Instância organizacional do Microsoft Entra onde o Microsoft Fabric e o Power BI são executados.
SKU
Stock Keeping Unit — identifica o tamanho/tipo de uma capacidade ou licença (ex: F64, P1).
Relatórios paginados
Relatórios pixel-perfect, prontos para impressão (como faturas), criados no Power BI Report Builder.
Analisar no Excel
Recurso que gera um arquivo Excel com conexão dinâmica a um modelo semântico do Power BI, para uso com tabelas dinâmicas.
Drillthrough
Recurso que permite navegar de um dado resumido até uma página de detalhe configurada para aquele contexto, com clique direito.
Bookmark (marcador)
Estado salvo de um relatório (filtros, seleções, visibilidade de objetos) que pode ser reaplicado com um clique.
Segurança em nível de linha (RLS)
Row-Level Security — restringe quais linhas de dados cada usuário pode ver em um relatório, com base em papéis (roles) e filtros.
Tema de relatório
Conjunto de cores, fontes e formatações padrão aplicado a todos os visuais de um relatório de uma só vez.
Performance Analyzer
Ferramenta do Power BI Desktop/service que mede o tempo de carregamento de cada visual em um relatório.
Translytical task flow
Recurso (preview) que permite escrever dados de volta na fonte diretamente a partir de um relatório, via user data functions do Fabric.
Slicer (segmentação de dados)
Controle visual de filtro colocado diretamente na tela do relatório — dropdown, lista, botão ou intervalo de datas.
Small multiples (múltiplos pequenos)
Recurso que repete o mesmo visual em uma grade, dividido por categoria, para comparar padrões lado a lado.
Decomposition tree
Visual de IA que sugere automaticamente a próxima dimensão a explorar em uma análise de causa raiz.
Key influencers
Visual de IA que identifica quais fatores mais influenciam o aumento ou a queda de uma métrica.
Matriz (matrix)
Visual do tipo tabela dinâmica, com hierarquias de linhas e colunas que podem ser expandidas e recolhidas.
Formatação condicional
Regras que alteram a aparência de um visual (cor, ícone, barra de dados) com base nos valores dos dados.
Visual calculation
Camada de cálculo semelhante ao DAX, definida diretamente sobre um visual, sem alterar o modelo de dados.
AI instructions
Instruções personalizadas que o autor de um modelo semântico escreve para orientar as respostas do Copilot sobre esses dados.
Verified answers
Pares de pergunta e resposta pré-aprovados que garantem que o Copilot responda corretamente a perguntas comuns sobre um modelo.
Narrativa inteligente (smart narrative)
Visual que gera automaticamente um resumo em texto, em linguagem natural, sobre os dados de uma página de relatório.
Layout mobile
Versão de uma página de relatório desenhada especificamente para telas de celular, criada na visualização de layout mobile do Power BI Desktop.
Meta (goal)
Métrica com uma meta (target) definida, acompanhada ao longo do tempo dentro de um scorecard.
Scorecard
Coleção de metas organizadas para acompanhar objetivos de negócio, individuais ou de equipe.
Meta conectada (connected goal)
Meta cujo valor atual é atualizado automaticamente a partir de um relatório ou modelo semântico, em vez de inserido manualmente.
Alerta de dados
Notificação configurada em um bloco de dashboard, disparada quando o valor cruza um limite definido.
